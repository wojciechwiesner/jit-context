## Lessons
- A release installer can have a broader scope than the requested runtime. Discover its profile targets before running it.
- An orphaned old HTTP process can keep serving outdated modules after a symlink replacement. Inspect the owner and restart only the intended service.
- Never label the current interactive process as reloaded merely because a cold-start gateway or child process imported the new snapshot.
